[odio-ha](https://github.com/b0bbywan/odio-ha) is a native Home Assistant integration, available in the Home Assistant [Marketplace](https://www.home-assistant.io/integrations/marketplace/). Each odio node appears as a single HA device with its stack exposed as entities.

A node can be a full [odio streamer](/operations/installation/) on a Raspberry Pi, or just [go-odio-api](/api/installation/) running on any Linux machine with a D-Bus user session (desktop, NAS, laptop). Same integration either way, HA exposes whichever capabilities the node actually has.

## Supported devices

Any Linux machine running [go-odio-api](/api/overview/) **v0.16.1 or later** with a D-Bus user session. See [platform support](/api/installation/#platform-support) for the tested architectures and distributions, and [compatible hardware](/operations/installation/#compatible-hardware) for full odio streamers.

The integration requires Home Assistant 2026.3 or later.

What a node exposes depends on the backends enabled in its [go-odio-api configuration](/api/configuration/): audio, systemd services, MPRIS players, Bluetooth, power, and upgrade. Each backend is optional, and HA only creates the [entities](/control/home-assistant/entities/) for the backends the node reports.

## Installation

1. Go to **Settings → Marketplace** in Home Assistant.
2. Search for **odio** or use the direct link:

   [![Open in the Marketplace](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=b0bbywan&repository=odio-ha&category=integration)

3. Select **Install**, then restart Home Assistant if asked.

Before Home Assistant 2026.11, the Marketplace was [HACS](https://hacs.xyz/), a separate integration to install first.

To install without the Marketplace, download the latest [release](https://github.com/b0bbywan/odio-ha/releases), copy `custom_components/odio_remote` into your Home Assistant `config/custom_components/` folder, and restart Home Assistant.

## Configuration

[![Install odio integration](https://my.home-assistant.io/badges/config_flow_start.svg)](https://my.home-assistant.io/redirect/config_flow_start/?domain=odio_remote)

Your odio nodes are auto-discovered via [Zeroconf](/api/zeroconf/) and show up under **Settings → Devices & services** with their hostname. Confirm the discovered node to add it.

To add a node manually, go to **Settings → Devices & services → Add integration**, search for **Odio Remote**, and enter the API URL (`http://<ip>:8018` with the default port).

The setup then asks for:

1. The **SSE keepalive interval**, 30 seconds by default.
2. Optional **service mappings** to existing Home Assistant media players.

Both can be changed later. See [options and mapping](/control/home-assistant/mapping/).

## Use cases

- [Phone and tablet](/guides/use-case-phone/): pair over Bluetooth, open pairing mode, and control playback from the Home Assistant companion app.
- [HTPC](/guides/use-case-htpc/): start and stop Kodi or a browser kiosk from Home Assistant.
- [Desktop](/guides/use-case-desktop/): control the volume of every desktop streaming to the node.
- [NAS](/guides/use-case-nas/): turn the NAS itself into an odio node.
- [Power](/operations/power/) and [upgrade](/operations/upgrade/#from-home-assistant-and-the-web-ui): shut down a node or apply an odio upgrade from Home Assistant.

## Removing the integration

1. Go to **Settings → Devices & services**, open **Odio Remote**, and select **Delete** from the node's menu.
2. If you installed it from the Marketplace, open **Odio Remote** in **Settings → Marketplace** and select **Uninstall** from the menu.

Removing the integration does not change anything on the node: go-odio-api keeps running.
