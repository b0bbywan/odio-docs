Every audio source (Spotify, Bluetooth, AirPlay, MPD, ...) exposes itself as an [MPRIS](https://specifications.freedesktop.org/mpris/latest/) player, and the [odio API](/api/overview/) discovers them all and provides a single interface to control playback, volume, and services. The clients below all build on it.
